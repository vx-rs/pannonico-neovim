*pannonico.txt*  Pannonico project intelligence

Pannonico requires Neovim 0.12.x.

SETUP                                                     *pannonico-setup*

    require('pannonico').setup()

Pass both `lsp_wasm_path` and `wasmtime_path` to use exact matching local files
without a download. The files must match the versions pinned by this plugin.

COMMANDS

                                                *:PannonicoStatus*
:PannonicoStatus
    Show the number of active Pannonico LSP clients.

                                                *:PannonicoRestart*
:PannonicoRestart
    Restart Pannonico LSP clients through Neovim's built-in lifecycle.
