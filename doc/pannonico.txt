*pannonico.txt*  Pannonico project intelligence

Pannonico requires Neovim 0.12 or newer.

SETUP                                                     *pannonico-setup*

    require('pannonico').setup()

Pass `lsp_path` to use an exact matching local native LSP without a download.

COMMANDS

                                                *:PannonicoStatus*
:PannonicoStatus
    Show the number of active Pannonico LSP clients.

                                                *:PannonicoRestart*
:PannonicoRestart
    Restart Pannonico LSP clients through Neovim's built-in lifecycle.
